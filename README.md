# Teguh Muhammad Harits — Portfolio

Portfolio publik berbasis Next.js dan Supabase dengan halaman proyek, case study, blog, serta SEO dinamis.

## Deployment

- Website utama: [teguhharits.com](https://teguhharits.com)
- Vercel: [teguh-portofolio-liard.vercel.app](https://teguh-portofolio-liard.vercel.app)

## Menjalankan lokal

```bash
npm install
npm run dev
```

Environment variables yang diperlukan:

```text
NEXT_PUBLIC_SITE_URL=https://teguhharits.com
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
```

Konten dikelola melalui CMS privat dan disimpan di Supabase.
